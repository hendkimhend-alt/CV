## 코드 파일별 기능

`final0/`의 .py 파일 전체. "그림자 수정"은 이번 작업에서 바뀐 내용이다.

### A. 실행기 (final0 바로 아래)

| 파일 | 기능 | 주요 함수 | 입력 → 출력 | 그림자 수정 |
|---|---|---|---|---|
| `run_final.py` | 최종 구성 메인 실행기. 사진마다 전처리 → 균열 · 포트홀 검출 → 노면 위 판정을 하고, 정답이 있으면 in50 기준으로 채점 | `prepare`: 노면 마스크 생성 (FAIL이면 검증 안 된 마스크로 진행) · 검출기 입력 만들기 / `detect_image`: 보정 → 균열(`detect`) + 포트홀(`texture_potholes`) → 마스크 50% 겹침만 남김 / `measure`: 에지 · 특징점 수 / `summarize`: 전체 · 그룹 · 폴더별 지표 | `--dataset`(기본 rdd_dev) · 설정 3개 → `final-result/run_<시각>/` (results.csv · summary.csv · detections.json · 그림) | 없음 |
| `run_final_PBL.py` | PBL 사진 폴더에 같은 처리를 하고 사진마다 그림 5장 저장 (정답 없어 채점 안 함) | `list_pbl`: 사진 목록 / `output_names`: 이름 겹침 처리 / `main`: 1 원본 · 2 노면 마스크 · 3 전처리 영상 · 4 균열 박스 · 5 노면+전체 박스 | `--input`(기본 `data/PBL module 1 - dataset`) → `final-result-PBL/run_<시각>/` | 없음 |
| `run_final_test.py` | `data/test/`의 사진에 최종 구성을 돌리고 원본 위에 박스만 그려 저장 | `main` | `--input`(파일 또는 폴더) → `final-result-test/run_<시각>/<이름>_bbox.jpg` | 없음 |

### B. 공통 · 평가 (`src/`)

| 파일 | 기능 | 주요 함수 | 입력 → 출력 | 그림자 수정 |
|---|---|---|---|---|
| `paths.py` | 공통 경로와 한글 경로에서도 되는 이미지 읽기 · 쓰기 | `imread` · `imwrite` · 경로 상수 (`DATA_DIR` 등) | 경로 → BGR 배열 / 파일 | 없음 |
| `data.py` | 데이터셋 이름이나 폴더로 사진 목록을 만들고 정답 박스를 읽음 | `list_images`: rdd_dev 등 분할 · 폴더 / `load_gt`: RDD json · csv 정답 (균열 3종 → crack) / `load_gt_file` / `load_viewpoints`: 촬영 시점 라벨 | `labels/*.csv` · 정답 파일 → 사진 목록 · 정답 로더 | 없음 |
| `evaluate.py` | 검출 박스와 정답 박스를 비교해 TP / FP / FN과 P · R · F1 계산 (iou50 · iou30 · in50) | `evaluate`: 사진 한 장 · 종류 · 기준별 집계 / `prf_in50`: 보고용 in50 지표 / `prf` | 검출 목록 · 정답 목록 → 집계 사전 | 없음 |

### C. 검출기 (`src/`, `src/road_detection/`)

| 파일 | 기능 | 주요 함수 | 입력 → 출력 | 그림자 수정 |
|---|---|---|---|---|
| `detect.py` | 균열 검출기. 전처리 영상(긴 변 1024)에서 균열 흔적을 찾고 모양 규칙 · 거르기로 crack / pothole / noise 판정 (최종 구성은 crack만 사용) | `detect` / `_crack_mask`: Black-hat 또는 Hessian 선 점수 / `line_trace` · `tensor_propagate`: 1px 흔적 · 방향 전파 / `classify` / `valley_score`: 한쪽만 어두운 그림자 경계 거르기 | 영상 · 설정(`detection_final.json`) → 후보 목록 | 없음 |
| `pothole.py` | 포트홀 2단계 검출기. 주변 노면 고리보다 거친 곳을 후보로 찾고 색도 차 · 어두운 10% · 세장비 · 높이 · 노면 색으로 검증 | `texture_potholes` / `ring_ratio`: 고리 비 (노면 마스크 안만) / `texture_z`: 행별 거칠기 z / `_box_cues` / `POTHOLE_DEFAULTS` | 영상 · 마스크 · 설정(`pothole_final.json`) → 포트홀 후보 | 없음 |
| `roadcue.py` | 후보 주변을 그 사진의 도로 표본(화면 높이 60~80% · 너비 30~70%)과 비교하는 단서 값 계산 | `maps` · `ref_stats` · `cue_values` · `onroad_values` · `line_resid` | 영상 · 후보 상자 → 단서 값 (색 · 밝기 · 구조 텐서 등) | 없음 |
| `road_detection/__init__.py` | 패키지 설명만 있음 (적혀 있는 `src/run_road_detection.py`는 이 폴더에 없음) | - | - | 없음 |
| `road_detection/config.py` | `detection_final.json`을 읽고 검사한 뒤 검출기 이름(예: D1hv)을 `detect()` 설정으로 바꿈 · opencv-contrib 필요 여부 확인 | `load_detection_config` · `detector_cfg` · `check_runtime` | `detection_final.json` → 설정 사전 | 없음 |
| `road_detection/pipeline.py` | 한 장 단위 연결 코드 (전처리 → 검출기 입력 → 보정 → 검출 → 노면 위 판정) | `road_overlap`: 박스 안 마스크 비율 (run_final은 이것만 씀) · `detect_on_road` · `run_image` | 영상 · 설정 → 후보 · 상태 | 없음 |
| `road_detection/render.py` | 검토용 그림: 원본 위에 마스크(초록 · 노란 윤곽)와 박스(균열 빨강 · 포트홀 파랑 · 도로 밖 회색) | `draw_result` · `review_sheet` | 영상 · 마스크 · 후보 → 그림 | 없음 |

### D. 전처리 · ROI (`src/preprocessing/`)

| 파일 | 기능 | 주요 함수 | 입력 → 출력 | 그림자 수정 |
|---|---|---|---|---|
| `__init__.py` | 패키지 설명만 있음 | - | - | 없음 |
| `config.py` | `preprocessing.json`을 읽고 설명용 `_` 키 제거 · 덮어쓰기 · 값 검사 | `load_config` · `apply_override` · `check_config` · `config_hash` | `preprocessing.json` → 설정 사전 | 없음 |
| `image_io.py` | 영상 · 마스크 읽기 · 쓰기와 형식 검사 (마스크 = uint8, 도로 255) | `validate_image` · `validate_mask` · `to_binary_mask` · `read_mask` | 파일 · 배열 → 검사된 영상 · 마스크 | 없음 |
| `pipeline.py` | 사진 한 장의 전처리 전체: 자동 노면 마스크 → 검증 → 최종 마스크 선택 → analysis_mask → 품질 측정 → 조건부 Gamma → 조건부 Gaussian | `process_image`: 상태(success / manual_required / error)와 결과 / `_choose_final_mask` / `save_result` | 영상 · 설정 → `PreprocessResult` (처리 영상 · road_mask · 메타데이터) | 없음 |
| **ROI** `road_mask.py` | 자동 노면 마스크 전체 순서: 축소(긴 변 1024 초과일 때만) → 특징 → 시드 → 영역 확장 → 정리 → 원본 크기 복원 (2-1) | `extract_road_mask` · `work_image` · `upsample_mask` | 원본 영상 · `roi` 설정 → 원본 크기 0/255 마스크 · 시드 기록 | 없음 |
| **ROI** `grid_features.py` | 화소 특징 지도(Lab · 기울기 · 질감)와 32px 칸 격자 특징 계산 (2-2) | `compute_feature_maps` · `compute_grid_features` · `color_distance` | 작업 영상 · `roi.features` · `roi.grid` → 특징 지도 · 격자 특징 | 없음 |
| **ROI** `seeds.py` | 칸마다 도로다움 점수(6요소 가중 기하평균)를 매기고 시드 선택 (2-3, 2-4) | `score_cells` · `select_seeds` · `consistent_with_best`: 1번 시드와 색 거리 · 밝기 · 질감 비교 | 격자 특징 · `roi.seeds` → 시드 목록 | **있음** (1단계): `consistent_with_best`의 밝기 제한을 밝은 쪽 25 / 어두운 쪽 `max_shadow_darkening_to_best`(50)로 분리 |
| **ROI** `region_growing.py` | 시드마다 조건을 만족하는 화소 중 시드 칸과 이어진 덩어리로 영역 확장 · 합집합 (2-5) | `seed_reference` · `color_threshold` · `acceptance_mask`: 화소 판정 · `grow_regions`: 연결 요소 · 채택 | 특징 지도 · 시드 · `roi.region_growing` → 작업 영상 크기 마스크 · 시드별 기록 | **있음** (2단계): `acceptance_mask`에 그림자 조건(OR) · 질감 하한 완화 · 높이 제한 추가, `grow_regions`가 시드 y좌표 전달 (4-3) |
| **ROI** `mask_refine.py` | 영역 확장 결과 정리: closing → opening → 작은 구멍 채우기 → 작은 조각 제거 (2-6) | `refine_mask` · `fill_holes` · `remove_small_components` | 마스크 · `roi.refine` → 정리된 마스크 | 없음 |
| **ROI** `mask_validation.py` | 마스크를 4개 지표(면적 · 최대 연결 요소 · 구멍 · 시드 일치)로 재고 PASS / FAIL (2-7) | `compute_mask_metrics` · `validate_road_mask` | 마스크 · 시드 좌표 · `validation` → 지표 · 판정 | 없음 |
| `analysis_mask.py` | road_mask를 5×5로 깎아 품질 측정용 analysis_mask 생성 (도로 경계 화소 제외) | `make_analysis_mask` | road_mask · `analysis_mask` 설정 → 마스크 · 충분 여부 | 없음 |
| `quality.py` | 마스크 안 품질 지표 8가지 측정 (밝기 평균 · 표준편차 · 블록 표준편차 · 어두운 / 밝은 / 포화 비율 · 선명도 · 노이즈) | `measure_in_masks` · `measure_quality` | 영상 · 마스크 · `quality` → 지표 사전 | 없음 |
| `gamma.py` | 어두운 노면에 조건부 Gamma 보정 (마스크 안에만, 후보 γ 중 조건이 풀리는 첫 값) | `decide_gamma` · `choose_gamma` · `apply_gamma` · `guard_triggered` | 품질 지표 · `gamma` → 판단 · 보정 영상 | 없음 |
| `gaussian.py` | 노이즈가 큰 사진에 조건부 Gaussian 블러 (마스크 안에만). 현재 `mode: off`라 적용 안 됨 | `decide_gaussian` · `masked_gaussian` | 품질 지표 · `gaussian` → 판단 · 블러 영상 | 없음 |
| `detector_adapter.py` | 전처리 결과를 검출기 입력으로 변환: 노면 외접 사각형(+16px)만 잘라 긴 변 1024로 맞춤 · 결과 좌표를 원본으로 되돌림 (2-8 ②) | `to_detector_input` · `road_bbox` · `to_original_bbox` | 처리 영상 · road_mask → 검출기 영상 · 마스크 · 좌표 정보 | 없음 |
| `detector_corrections.py` | 검출기 바로 앞 보정 (마스크 안에만): 흐림 판단 후 가우시안 · 막대 닫힘 또는 언샤프, 그리고 CLAHE (2-8 ③) | `apply_corrections` · `judge_tags` · `road_sharpness` · `line_close` | 검출기 영상 · 마스크 · `detection_final.json`의 `corrections` → 보정 영상 | 없음 |

실행 흐름으로 보면: `run_final.py` → `preprocessing/pipeline.py`(→ `road_mask.py` → `grid_features` · `seeds` · `region_growing` · `mask_refine` → `mask_validation` → `analysis_mask` · `quality` · `gamma` · `gaussian`) → `detector_adapter.py` → `detector_corrections.py` → `detect.py`(균열) + `pothole.py`(포트홀) → `road_detection/pipeline.road_overlap`(노면 위 판정) → `evaluate.py`(채점) → `road_detection/render.py`(그림).
