#### 지표 정의 (`src/evaluate.py`)

| 지표 | 정의 |
|---|---|
| 맞춤 (hit) | 정답 박스 중 검출된 수. 후보 면적의 50% 이상이 정답 박스 안이면 맞춤 (**in50 기준**, 같은 정답 안 추가 조각은 제외) |
| 오검출 (fake) | 어떤 정답 박스와도 맞지 않은 후보 수 |
| Recall | 맞춤 ÷ 정답 수 |
| Precision | (후보 수 − 오검출) ÷ 후보 수 |
| F1 | Recall과 Precision의 조화평균 |
| 노면 비율 | 노면 마스크 면적 ÷ 영상 면적 |
| 검증 안 된 마스크 | 마스크 검증 FAIL인데 비어 있지 않아 그대로 검출에 쓴 사진 |
| 마스크 바뀐 사진 | 노면 비율이 **0.5%p 넘게** 바뀐 사진 (조금이라도 바뀐 사진은 434장, 그중 215장은 0.5%p 이내) |

### 5-4. rdd_dev 563장 — 매칭 기준별

보고 지표는 in50이지만, 더 엄격한 IoU 기준에서도 확인했다 (TP / FP / FN 합계).

| 종류 | 기준 | 수정 전 TP / FP / FN | 수정 후 TP / FP / FN | TP 변화 |
|---|---|---|---|---|
| 균열 | IoU > 0.5 | 19 / 5646 / 725 | 19 / 5623 / 725 | 0 |
| 균열 | IoU > 0.3 | 51 / 5614 / 693 | 51 / 5591 / 693 | 0 |
| 균열 | in50 | 437 / 3665 / 307 | 433 / 3662 / 311 | −4 |
| 포트홀 | IoU > 0.5 | 11 / 1197 / 83 | 11 / 1250 / 83 | 0 |
| 포트홀 | IoU > 0.3 | 23 / 1185 / 71 | 24 / 1237 / 70 | +1 |
| 포트홀 | in50 | 39 / 1156 / 55 | 38 / 1210 / 56 | −1 |

- in50의 TP + FP는 후보 수와 다르다 (예: 437 + 3665 = 4102 < 5665). 같은 정답 박스 안의 추가 조각은 TP도 FP도 아닌 것으로 빼기 때문이다.
- IoU 기준에서는 맞춤이 거의 그대로다. 포트홀 FP 증가는 기준과 관계없이 +52 ~ +54로 비슷하다.
